# 🍕 Pizzaria — Landing Page

Minha primeira landing page: uma página de apresentação para uma pizzaria, com cardápio de sabores, seção do chef e chamada para pedido.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como rodar

Não precisa de instalação. Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/andreluaan/Pizzaria-landingpage.git
```

## Estrutura

```
index.html
src/
  img/         imagens das pizzas e do chef
  javascript/  scripts da página
  styles/      folhas de estilo
```
